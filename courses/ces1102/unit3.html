Unit 3 lessons

    Unit 3: Arrays and strings

    So far each variable held one value. Real problems involve 60 students' marks, a 3 × 3 matrix or a name. Arrays let one name hold many values, and this unit shows how to search, sort and process them.

    3.1

    One-dimensional arrays

    Lecture L14 with tutorial T5

    A row of numbered lockers in a hostel corridor. One corridor name, many lockers, and the numbering starts at 0.

    An array is a fixed-size collection of elements of the same type, stored next to each other in memory. int marks[5]; creates five ints called marks[0] to marks[4]. The number in brackets at declaration is the size; the number in brackets later is the index, which runs from 0 to size − 1.

    You can initialise at declaration: int a[5] = {1, 2, 3}; fills the rest with 0, and int a[] = {4, 5, 6}; lets the compiler count the size (3). Arrays and for loops are natural partners, because the loop counter becomes the index.

    C does no bounds checking. Writing to marks[5] compiles, then quietly overwrites some other memory. That bug is behind many crashes and security holes, so check your loop limits.

    int marks[5], sum = 0;
for (int i = 0; i < 5; i++) {       // read
    scanf("%d", &marks[i]);
    sum += marks[i];
}
printf("Average = %.2f\n", (float)sum / 5);

    Traps that cost marks

    • The last valid index of int a[10] is 9. A loop with i <= 10 goes one past the end.
    • Arrays cannot be copied with =. b = a; is an error; copy element by element in a loop.
    • The size must be a constant in the traditional C taught here. Read n first and declare a large enough array, such as int a[100];.

    3.2

    Searching: linear and binary

    Lecture L16

    Finding a word in a dictionary: you never read from page 1. You open the middle and throw away half the book. That is binary search.

    Linear search checks elements one by one from the start until it finds the key or runs out. It works on any array, sorted or not. In the worst case it makes n comparisons.

    Binary search works only on a sorted array. It compares the key with the middle element. If they match, it is done; if the key is smaller, it keeps the left half; if bigger, the right half. Each comparison halves the search space, so 1,000 elements need at most about 10 comparisons, and a million need about 20.

    int low = 0, high = n - 1, mid, pos = -1;
while (low <= high) {
    mid = (low + high) / 2;
    if (a[mid] == key) { pos = mid; break; }
    else if (key < a[mid]) high = mid - 1;   // keep left half
    else low = mid + 1;                       // keep right half
}
if (pos == -1) printf("Not found");
else printf("Found at index %d", pos);
    Linear searchBinary search
    Needs sorted data?NoYes
    Worst-case comparisonsnabout log₂ n
    1,000 elementsup to 1,000up to 10
    Best forSmall or unsorted listsLarge sorted lists

    Traps that cost marks

    • Running binary search on unsorted data gives wrong answers without any error.
    • The loop condition is low <= high. Using < misses the case where the key is the last remaining element.
    • Update with mid - 1 and mid + 1. Using high = mid can loop forever.

    3.3

    Sorting: selection and bubble

    Lecture L17

    Arranging students by height for a class photo. Either keep swapping neighbours who are out of order (bubble), or pick the shortest and send them to the front each time (selection).

    Bubble sort compares each pair of neighbours and swaps them if they are in the wrong order. After pass 1 the largest value has bubbled to the end; after pass 2 the second largest is in place, and so on. If a pass makes no swaps, the array is already sorted and you can stop early.

    Selection sort finds the smallest element in the unsorted part and swaps it into the first unsorted position. It makes the same number of comparisons as bubble sort, n(n − 1)/2, but at most n − 1 swaps, which is useful when moving data is expensive.

    Run both on the same array below and compare the counters.

    Traps that cost marks

    • The inner loop of bubble sort runs to n - 1 - i, because a[j + 1] must stay inside the array.
    • A swap needs a temporary variable. a[j] = a[j+1]; a[j+1] = a[j]; loses a value.
    • For descending order, flip only the comparison: > becomes <.

    3.4

    Two-dimensional arrays and matrices

    Lectures L18, L19 and tutorial T6

    A cinema seat is "row C, seat 7". A 2-D array element is a[row][column]. Same idea.

    int a[3][4]; is a table of 3 rows and 4 columns: 12 ints. Element a[i][j] is row i, column j, both counted from 0. Memory is a single line, so C stores the table row by row (row-major order): all of row 0, then all of row 1, and so on. Click any cell below to see where it lives.

    Initialise row by row: int m[2][3] = {{1, 2, 3}, {4, 5, 6}};. Processing a matrix uses nested loops: the outer loop picks the row, the inner loop walks the columns.

    Traps that cost marks

    • Write a[i][j], not a[i, j]. The comma version compiles but means something else entirely.
    • Matrix multiplication needs columns of A to equal rows of B. Check this and print an error first.
    • Reset the sum to 0 for every cell in multiplication, inside the j loop, not outside it.

    3.5

    Strings

    Lecture L20

    A string is a train of characters, and '\0' is the guard's van at the end. Without it, nobody knows where the train stops.

    C has no separate string type. A string is a char array that ends with the null character '\0' (value 0). char name[10] = "Ravi"; stores R, a, v, i, then '\0', and the remaining slots are also 0. Always size the array one larger than the longest text you expect.

    Reading strings: scanf("%s", name); needs no & (the array name is already an address) but stops at the first space, so "Ravi Kumar" becomes "Ravi". To read a whole line, use fgets(name, sizeof name, stdin);, which also keeps the newline. Avoid gets: it was removed from C because it cannot stop at the array size.

    Every string program walks characters until it meets '\0'. The tracer below shows the classic one: counting the length.

    char s[50];
int vowels = 0;
fgets(s, sizeof s, stdin);
for (int i = 0; s[i] != '\0'; i++) {
    char c = s[i];
    if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u'||
        c=='A'||c=='E'||c=='I'||c=='O'||c=='U')
        vowels++;
}
printf("Vowels = %d\n", vowels);

    Security note

    A string read without a size limit is the classic buffer overflow. Always give scanf a width (%19s for char s[20]) or use fgets. Lesson 5.6 Writing secure C shows what goes wrong.

    Traps that cost marks

    • char name[4] = "Ravi"; leaves no room for '\0'. Printing it can show garbage.
    • name = "Ravi"; after declaration is an error. Use strcpy (next lesson).
    • '0' (the digit, value 48) is not '\0' (the terminator, value 0).

    3.6

    String functions and sorting names

    Lecture L21 with tutorial T7

    Why write the same length-counting loop every time? string.h is a toolbox of ready-made string functions.

    Include <string.h> to use them. strlen(s) counts characters before '\0'. strcpy(dest, src) copies src into dest. strcat(dest, src) joins src onto the end of dest. strcmp(a, b) compares alphabetically: 0 if equal, negative if a comes first, positive if b comes first. Some compilers also offer strrev, strupr and strlwr, but they are not standard C, so gcc does not have them.

    The destination must be big enough. C trusts you, so strcat into a small array overflows memory. Try it in the lab below: s1 has room for 16 characters.

    Sorting names is bubble sort with two changes: compare with strcmp, and swap with strcpy through a temporary string.

    char names[5][20], temp[20];
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (strcmp(names[j], names[j + 1]) > 0) {
            strcpy(temp, names[j]);
            strcpy(names[j], names[j + 1]);
            strcpy(names[j + 1], temp);
        }

    Security note

    strcpy and strcat never check the destination size. Before copying, make sure strlen(src) < sizeof dest (and for strcat, that both lengths together fit), or use snprintf(dest, sizeof dest, "%s", src), which always stops in time. See lesson 5.6.

    Traps that cost marks

    • if (s1 == s2) compares addresses, not text. Use strcmp(s1, s2) == 0.
    • strcmp is case-sensitive, and uppercase letters come before lowercase in ASCII: "Zoya" sorts before "anu".
    • strlen does not count '\0', but the array needs space for it: size = strlen + 1.

    Easy

    3A. Reverse an array in place

    Practises lesson 3.1

    Read n and n integers, reverse the array without using a second array, and print it.

    Sample input
    5
1 2 3 4 5
    Expected output
    5 4 3 2 1
    Hint

    Swap a[i] with a[n - 1 - i], but only for the first half.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, a[100];
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    for (int i = 0; i < n / 2; i++) {
        int t = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = t;
    }
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}

    Looping all the way to n would swap every pair twice and put the array back as it was.

    Easy

    3B. Count positive, negative, even and odd

    Practises lesson 3.1

    Read n integers into an array and count how many are positive, negative and zero, and how many are even and odd.

    Sample input
    6
4 -3 0 7 -8 5
    Expected output
    Positive 3, Negative 2, Zero 1
Even 3, Odd 3
    Hint

    One loop, two independent tests per element.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, a[100], pos = 0, neg = 0, zero = 0, even = 0, odd = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
        if (a[i] > 0) pos++;
        else if (a[i] < 0) neg++;
        else zero++;
        if (a[i] % 2 == 0) even++;
        else odd++;
    }
    printf("Positive %d, Negative %d, Zero %d\n", pos, neg, zero);
    printf("Even %d, Odd %d\n", even, odd);
    return 0;
}

    Sign and parity are separate questions, so they are two separate if statements. -8 % 2 is 0 in C, so negatives are classified correctly.

    Medium

    3C. Second largest element in one pass

    Practises lesson 3.1

    Find the second largest distinct value in an array using a single loop.

    Sample input
    6
12 45 7 45 30 9
    Expected output
    Second largest = 30
    Hint

    Track first and second. A new maximum pushes the old first down to second.

    Show solution
    #include <stdio.h>
#include <limits.h>
int main(void)
{
    int n, a[100], first = INT_MIN, second = INT_MIN;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    for (int i = 0; i < n; i++) {
        if (a[i] > first) {
            second = first;
            first = a[i];
        } else if (a[i] > second && a[i] != first) {
            second = a[i];
        }
    }
    if (second == INT_MIN) printf("No second largest\n");
    else printf("Second largest = %d\n", second);
    return 0;
}

    The a[i] != first test stops a repeated maximum (45 twice) from being reported as the second largest. INT_MIN from limits.h is the smallest int.

    Medium

    3D. Insert an element at a position

    Practises lesson 3.1

    Read an array, then a value and an index. Insert the value at that index, shifting later elements right.

    Sample input
    5
10 20 30 40 50
25 2
    Expected output
    10 20 25 30 40 50
    Hint

    Shift from the end backwards, otherwise you overwrite values before moving them.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, a[101], val, pos;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    scanf("%d %d", &val, &pos);
    if (pos < 0 || pos > n) { printf("Invalid position\n"); return 0; }
    for (int i = n; i > pos; i--)
        a[i] = a[i - 1];
    a[pos] = val;
    n++;
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}

    The array is declared one larger than the maximum input so there is room to grow. Valid positions run from 0 to n, inclusive.

    Medium

    3E. Is the matrix symmetric?

    Practises lesson 3.4

    Read an n × n matrix and print whether it is symmetric, that is, equal to its transpose.

    Sample input
    3
1 2 3
2 5 6
3 6 9
    Expected output
    Symmetric
    Hint

    Check a[i][j] == a[j][i] for every pair. Stop at the first mismatch.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, a[10][10], sym = 1;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            scanf("%d", &a[i][j]);
    for (int i = 0; i < n && sym; i++)
        for (int j = 0; j < i; j++)
            if (a[i][j] != a[j][i]) { sym = 0; break; }
    printf(sym ? "Symmetric\n" : "Not symmetric\n");
    return 0;
}

    Checking only j < i compares each pair once and skips the diagonal. The flag in the outer condition ends both loops after a mismatch.

    Medium

    3F. Palindrome string without a library reverse

    Practises lesson 3.5

    Read a word and check whether it is a palindrome, without using strrev.

    Sample input
    madam
    Expected output
    madam is a palindrome
    Hint

    Compare from both ends moving inwards: s[i] with s[len - 1 - i].

    Show solution
    #include <stdio.h>
#include <string.h>
int main(void)
{
    char s[50];
    int ok = 1;
    scanf("%49s", s);
    int len = strlen(s);
    for (int i = 0; i < len / 2; i++)
        if (s[i] != s[len - 1 - i]) { ok = 0; break; }
    printf("%s is %sa palindrome\n", s, ok ? "" : "not ");
    return 0;
}

    %49s stops scanf from writing past the 50-byte array. Only half the word needs checking.

    Exam level

    3G. Count words, vowels and digits in a line

    Practises lesson 3.5, 3.6

    Read a full line (with spaces) and count its words, vowels, digits and spaces.

    Sample input
    C lab 2026 is fun
    Expected output
    Words 5, Vowels 3, Digits 4, Spaces 4
    Hint

    A new word starts where a non-space character follows a space (or the start of the line).

    Show solution
    #include <stdio.h>
#include <ctype.h>
int main(void)
{
    char s[200];
    int words = 0, vowels = 0, digits = 0, spaces = 0, inWord = 0;
    fgets(s, sizeof s, stdin);
    for (int i = 0; s[i] != '\0' && s[i] != '\n'; i++) {
        char c = tolower((unsigned char)s[i]);
        if (c == ' ') { spaces++; inWord = 0; }
        else if (!inWord) { words++; inWord = 1; }
        if (c=='a' || c=='e' || c=='i' || c=='o' || c=='u') vowels++;
        if (isdigit((unsigned char)c)) digits++;
    }
    printf("Words %d, Vowels %d, Digits %d, Spaces %d\n", words, vowels, digits, spaces);
    return 0;
}

    The inWord flag counts words correctly even with several spaces between them. fgets keeps the newline, so the loop also stops at \n.

    Exam level

    3H. Row and column sums of a matrix

    Practises lesson 3.4

    Read an r × c matrix and print it with the sum of each row at the end of the row and the sum of each column underneath.

    Sample input
    2 3
1 2 3
4 5 6
    Expected output
       1   2   3  | 6
   4   5   6  | 15
   5   7   9
    Hint

    Row sums can be printed while printing the row. Column sums need a separate pair of loops with the order swapped.

    Show solution
    #include <stdio.h>
int main(void)
{
    int r, c, a[10][10];
    scanf("%d %d", &r, &c);
    for (int i = 0; i < r; i++)
        for (int j = 0; j < c; j++)
            scanf("%d", &a[i][j]);
    for (int i = 0; i < r; i++) {
        int rs = 0;
        for (int j = 0; j < c; j++) {
            printf("%4d", a[i][j]);
            rs += a[i][j];
        }
        printf("  | %d\n", rs);
    }
    for (int j = 0; j < c; j++) {
        int cs = 0;
        for (int i = 0; i < r; i++) cs += a[i][j];
        printf("%4d", cs);
    }
    printf("\n");
    return 0;
}

    For column sums the outer loop runs over columns and the inner loop over rows. %4d keeps the columns aligned.

    Unit 3 cheat sheet

    The night before: the syntax you must not mix up

    One-dimensional arrays

    One name, many values of the same type, numbered from 0.

    int a[5] = {1, 2, 3}; // 0s
a[0]   // first element
a[4]   // last: size - 1
for (i = 0; i < 5; i++)
    sum += a[i];

    Watch out: C never checks the index: a[5] silently writes outside the array. Copy arrays with a loop, not =.

    Searching

    Linear search checks one by one. Binary search halves a sorted array each time.

    mid = (low + high) / 2;
if (a[mid] == key) found;
else if (key < a[mid])
    high = mid - 1;
else
    low = mid + 1;

    Compare: Linear: any order, up to n comparisons. Binary: sorted data only, about log₂ n comparisons (10 for 1,000 items).

    Sorting

    Bubble sort swaps neighbours; selection sort picks the minimum and swaps it to the front.

    // bubble: neighbours
if (a[j] > a[j + 1]) {
    int t = a[j];
    a[j] = a[j + 1];
    a[j + 1] = t;
}

    Remember: Both make n(n − 1)/2 comparisons. Selection makes at most n − 1 swaps. A swap always needs a temporary variable.

    Two-dimensional arrays

    A table of rows and columns, stored row after row.

    int m[3][4];  // 3 x 4
m[i][j]       // row i, col j
// offset = i * 4 + j
for (i = 0; i < 3; i++)
  for (j = 0; j < 4; j++)
    ...

    Watch out: Write m[i][j], never m[i, j]. Multiply A × B only when columns of A equal rows of B.

    Strings

    A string is a char array that ends with '\0'.

    char s[10] = "Ravi";
// R a v i \0 \0 ...
scanf("%s", s); // to a space
fgets(s, sizeof s, stdin);
// reads the whole line

    Watch out: Size = text length + 1 for the '\0'. scanf with %s needs no &. Never use gets.

    string.h functions

    Ready-made tools for common string jobs.

    strlen(s)     // no \0 counted
strcpy(d, s)  // d = copy of s
strcat(d, s)  // add s to d
strcmp(a, b)  // 0 if equal

    Watch out: Compare text with strcmp(a, b) == 0, never a == b. The destination must be big enough.
