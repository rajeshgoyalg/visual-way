How marks are given

Marks are awarded for each step, so write the steps even when you are unsure of the final answer. For a program: the declarations and input, the main logic, and the output each earn marks. For a predict-the-output question: show how each value is worked out. For a trace: write every step, not just the answer. Under time pressure, attempt every part; a blank earns nothing.
