Unit 5 lessons

    Unit 5: Structures and files

    Real data comes in records: a student has a roll number, a name and marks. This unit groups related data into structures, uses pointers to move through memory efficiently, and saves data in files so it survives after the program ends.

    5.1

    Structures and arrays of structures

    Lecture L30 with tutorial T10

    An ID card holds different kinds of information about one person on one card. A structure does the same for one record.

    A structure is a user-defined type that groups related variables, called members, under one name. Defining struct student { ... }; creates a new type, a template; it does not use memory. Declaring struct student s1; creates an actual variable.

    Use the dot operator to reach a member: s1.marks = 88.5;. Structures of the same type can be copied in one go with s2 = s1; (unlike arrays), but they cannot be compared with ==; compare member by member.

    An array of structures stores a whole class: struct student cls[60];. Then cls[i].marks is the marks of the i-th student, which is how you build a mark list, find the topper or sort by marks.

    struct student {
    int roll;
    char name[20];
    float marks;
};                                      // semicolon required

int main(void)
{
    struct student cls[3];
    int top = 0;
    for (int i = 0; i < 3; i++) {
        scanf("%d %19s %f", &cls[i].roll, cls[i].name, &cls[i].marks);
        if (cls[i].marks > cls[top].marks) top = i;
    }
    printf("Topper: %s (%.1f)\n", cls[top].name, cls[top].marks);
    return 0;
}

    Traps that cost marks

    • The semicolon after the closing brace of a structure definition is mandatory.
    • s1.name = "Asha"; is an error, because name is an array. Use strcpy(s1.name, "Asha");.
    • sizeof a structure can be larger than the sum of its members, because the compiler may add padding for alignment.

    5.2

    Nested structures and pointers to structures

    Lectures L31 and L32

    A box inside a box. An employee record contains a date of birth, and a date is itself a small record of day, month and year.

    A nested structure has a structure as one of its members. Reach inner members by chaining dots: e.dob.year.

    A pointer to a structure stores the structure's address: struct student *p = &s1;. To reach a member through it, write (*p).marks, with the brackets because the dot outranks the star. That is clumsy, so C gives the arrow operator: p->marks means exactly the same thing. The rule: use a dot with a structure variable, an arrow with a pointer to a structure.

    Why bother? Passing a pointer to a large structure into a function copies just one address instead of the whole record, and it lets the function update the original.

    struct date { int day, month, year; };
struct employee {
    char name[20];
    struct date dob;               // nested structure
};
struct employee e = {"Kiran", {15, 8, 2004}};
printf("%s was born in %d\n", e.name, e.dob.year);

void raise(struct student *p) { p->marks += 5; }   // updates the caller's record

    Traps that cost marks

    • *p.marks means *(p.marks), which is an error. Write (*p).marks or p->marks.
    • s1->marks is wrong when s1 is a structure variable, not a pointer.
    • An inner structure type must be defined before the outer one uses it.

    5.3

    Pointer arithmetic, arrays and strings

    Lecture L33 with tutorial T11

    Houses on a street are numbered by plot, not by brick. p + 1 means "next plot", however wide the plots are.

    Adding 1 to a pointer moves it to the next element, not the next byte. If p is an int * holding 1000, then p + 1 is 1004, because an int is 4 bytes. For a double * it would be 1008. The compiler scales by sizeof the type for you. You can add or subtract an integer, use ++ and --, and subtract two pointers into the same array to get the number of elements between them. Adding two pointers makes no sense and is not allowed.

    Arrays and pointers are closely tied. An array name used in an expression is the address of its first element, so int *p = a; is the same as p = &a[0];. And a[i] is defined as *(a + i). The difference: p is a variable you can move, while a is fixed, so a++ is an error.

    Strings work the same way, because a string is a char array. Walking a char * until it hits '\0' is the pointer version of strlen:

    int myStrlen(const char *s)
{
    const char *start = s;
    while (*s != '\0')
        s++;                 // move to the next character
    return s - start;        // pointer difference = number of characters
}
char a[] = "Hello";          // a copy you may change
const char *b = "World";     // points at a literal: do not modify it

    Traps that cost marks

    • *p + 1 adds 1 to the value; *(p + 1) reads the next element. Brackets matter.
    • *p++ reads the current element, then moves p. It does not increment the value.
    • Modifying a string literal through char *b = "World"; is undefined behaviour and often crashes.

    5.4

    Pointers with 2-D arrays and arrays of pointers

    Lecture L34

    A bookshelf where every shelf must be the width of the widest book, versus a row of hooks where each bag hangs at its own length.

    A 2-D array is an array of rows. For int a[3][4], a[i] is row i (itself an array of 4 ints), so a + i jumps a whole row of 16 bytes. Combining both levels gives the pointer form of every element: a[i][j] is *(*(a + i) + j). Read it inside out: move to row i, then to column j within it, then read.

    An array of pointers is an array whose elements are addresses: int *ptr[3]; holds three int addresses. Its most common use is a list of strings: const char *names[] = {"Asha", "Ravi", "Shalini"};. Each string takes only the space it needs, unlike a 2-D char array where every row is as long as the longest name. Sorting names then means swapping pointers, which is far cheaper than copying text with strcpy.

    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
printf("%d %d\n", a[1][2], *(*(a + 1) + 2));     // both print 6

const char *days[] = {"Mon", "Tue", "Wed", "Thu", "Fri"};
for (int i = 0; i < 5; i++)
    printf("%s ", days[i]);

const char *t = days[0]; days[0] = days[4]; days[4] = t;   // swap two names: only addresses move

    Traps that cost marks

    • int *p[3] is an array of 3 pointers. int (*p)[3] is one pointer to an array of 3 ints. The brackets change everything.
    • For int a[3][4], a + 1 moves 16 bytes (one row) but a[0] + 1 moves 4 bytes (one int).
    • Strings in an array of pointers to literals cannot be edited with strcpy. Use a 2-D char array if you need to change them.

    5.5

    Files

    Lectures L35, L36 and tutorial T12

    RAM is a whiteboard, wiped when the class ends. A file is a notebook you take home.

    Everything a program stores in variables disappears when it ends. A file keeps data on disk permanently, so it can be read again later or by another program. C handles files through a FILE * pointer, and every file program follows the same three-step rhythm: open, use, close.

    fopen("name", "mode") opens a file and returns a FILE *, or NULL if it fails, for example when reading a file that does not exist. Always check for NULL. Then read or write with the file versions of familiar functions: fprintf and fscanf (formatted), fputc and fgetc (one character), fputs and fgets (one line). Finally fclose(fp) saves any buffered data and releases the file. Reading functions signal the end of the file with EOF (for fgetc and fscanf) or NULL (for fgets).

    ModeMeaningIf the file existsIf it does not
    "r"ReadOpens from the startfopen returns NULL
    "w"WriteErases its contentsCreates it
    "a"AppendWrites are added at the endCreates it
    "r+" "w+" "a+"Read and writeSame create and erase rules as r, w and a. Add b (such as "rb") for binary files.
     
    #include <stdio.h>
int main(void)
{
    FILE *fp = fopen("marks.txt", "w");
    if (fp == NULL) { printf("Cannot open file\n"); return 1; }
    fprintf(fp, "%d %d\n", 101, 88);
    fprintf(fp, "%d %d\n", 102, 74);
    fclose(fp);

    int roll, m;
    fp = fopen("marks.txt", "r");
    if (fp == NULL) { printf("Cannot open file\n"); return 1; }
    while (fscanf(fp, "%d %d", &roll, &m) == 2)   // stops at end of file
        printf("Roll %d scored %d\n", roll, m);
    fclose(fp);
    return 0;
}

    Traps that cost marks

    • Opening an existing file with "w" erases it instantly. Use "a" to add to it.
    • Skipping the NULL check means the program crashes on the first read if the file is missing.
    • Store the result of fgetc in an int, not a char, so EOF (usually -1) can be told apart from real characters.

    5.6

    Writing secure C

    Learning outcome C1: problems that pertain to computer security

    C trusts you completely. It will copy 50 characters into a 10-character array without complaint. Most security holes in C programs come from a handful of mistakes you have already met in this course.

    A buffer overflow happens when a program writes past the end of an array. The extra bytes land on whatever sits next to the array in memory: another variable, or the information a function needs to return safely. An attacker who controls the input can choose those bytes. The Morris worm of 1988, one of the first worms to spread across the internet, got into computers through exactly this mistake: a server program read input with gets, which has no way to stop at the end of the array.

    The lab below shows the idea. name has room for 7 characters plus '\0', and an isAdmin flag sits right after it. Type a longer name and watch what strcpy does, then switch to the safe version.

    Risky codeWhat can go wrongSafer habit
    gets(s);No length limit at all; removed from the C languagefgets(s, sizeof s, stdin);
    scanf("%s", s);A long word overflows sGive a width one less than the size: scanf("%19s", s); for char s[20]
    strcpy(d, s); strcat(d, s);The destination can be too smallCheck strlen first, or use snprintf(d, sizeof d, "%s", s);
    a[i] = x; with i from the userWrites outside the arrayCheck 0 <= i && i < n before using i
    printf(text);A % in the text is treated as a format code and reads or writes memoryprintf("%s", text);
    scanf("%d", &n); with no checkLetters leave n unset, and later code uses garbageCheck that scanf returned 1, and check the range
    int f = 1; for 20!Integer overflow gives wrong, even negative, resultsUse a wider type such as unsigned long long and check limits
    int *p; *p = 5;Writes to a random addressInitialise pointers: int *p = NULL; and check before use
    fp = fopen(...); with no checkA missing file crashes the programif (fp == NULL) { ... }

    The most useful habit of all is to validate input: never assume the user typed what you asked for. This loop keeps asking until it gets a whole number in range, and throws away anything else that was typed.

    int marks, c, r;
printf("Marks (0 to 100): ");
while ((r = scanf("%d", &marks)) != 1 || marks < 0 || marks > 100) {
    if (r == EOF) return 1;             /* no input left at all */
    while ((c = getchar()) != '\n' && c != EOF) {
        /* discard the rest of the bad line */
    }
    printf("Please type a whole number from 0 to 100: ");
}

    Traps that cost marks

    • char s[10] holds at most 9 characters plus '\0'. The width in scanf is therefore 9: %9s.
    • strncpy(d, s, n) does not add '\0' when s is too long. Add it yourself: d[n - 1] = '\0';
    • "It worked when I tested it" proves nothing about long or unexpected input. Test with empty, very long and wrong-type input too.

103 Meena 79
    Expected output
    101 Asha 88.5

    Hint

    struct student cls[50]; then read cls[i].roll, cls[i].name and cls[i].marks in a loop.

    Show solution

struct student {

    for (int i = 0; i < n; i++)

    Medium

    5B. Rank list: sort structures by marks

    Practises lesson 5.1, 3.3

    Read n student records and print a rank list, highest marks first.

    Sample input
    4
101 Asha 88.5
102 Ravi 64
103 Meena 79
104 Kiran 91
    Expected output
    Rank 1: Kiran (104) 91.0
Rank 2: Asha (101) 88.5
Rank 3: Meena (103) 79.0
Rank 4: Ravi (102) 64.0
    Hint

    Bubble sort on cls[j].marks, but swap whole structures. Structures can be copied with =.

    Show solution
    #include <stdio.h>
struct student { int roll; char name[20]; float marks; };
int main(void)
{
    struct student cls[50], t;
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        scanf("%d %19s %f", &cls[i].roll, cls[i].name, &cls[i].marks);
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (cls[j].marks < cls[j + 1].marks) {    /* < for descending */
                t = cls[j]; cls[j] = cls[j + 1]; cls[j + 1] = t;
            }
    for (int i = 0; i < n; i++)
        printf("Rank %d: %s (%d) %.1f\n", i + 1, cls[i].name, cls[i].roll, cls[i].marks);
    return 0;
}

    Swapping whole records keeps each name with its own marks. Swapping only the marks would scramble the list.

    5C. Earliest joiner: nested structures

    Practises lesson 5.2

    Each employee has a name and a joining date (day, month, year) stored as a nested structure. Find who joined first.

    Sample input
    3
Kiran 15 8 2019
Divya 2 3 2018
Arjun 20 11 2018
    Expected output
    Earliest joiner: Divya (02/03/2018)
    Hint

    Compare years, then months if the years are equal, then days.

    Show solution
    #include <stdio.h>
struct date { int d, m, y; };
struct employee { char name[20]; struct date join; };
int earlier(struct date a, struct date b)      /* 1 if a is before b */
{
    if (a.y != b.y) return a.y < b.y;
    if (a.m != b.m) return a.m < b.m;
    return a.d < b.d;
}
int main(void)
{
    struct employee e[20];
    int n, first = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        scanf("%19s %d %d %d", e[i].name, &e[i].join.d, &e[i].join.m, &e[i].join.y);
    for (int i = 1; i < n; i++)
        if (earlier(e[i].join, e[first].join)) first = i;
    printf("Earliest joiner: %s (%02d/%02d/%d)\n", e[first].name,
           e[first].join.d, e[first].join.m, e[first].join.y);
    return 0;
}

    e[i].join.y chains two dots: array element, then the nested structure, then its member. Passing struct date to a function copies it, which is fine for a small record.

    5D. Update a record through a pointer

    Practises lesson 5.2

    Write void addBonus(struct student *p, float bonus) that adds a bonus to a student’s marks without letting them exceed 100.

    Sample input
    101 Asha 96
5
    Expected output
    101 Asha 100.0
    Hint

    Use the arrow operator: p->marks. Pass &s from main.

    Show solution
    #include <stdio.h>
struct student { int roll; char name[20]; float marks; };
void addBonus(struct student *p, float bonus)
{
    p->marks += bonus;
    if (p->marks > 100) p->marks = 100;
}
int main(void)
{
    struct student s;
    float b;
    scanf("%d %19s %f", &s.roll, s.name, &s.marks);
    scanf("%f", &b);
    addBonus(&s, b);
    printf("%d %s %.1f\n", s.roll, s.name, s.marks);
    return 0;
}

    Only an address is passed, so the function edits main’s record directly instead of a copy.

    5E. Reverse an array with two pointers

    Practises lesson 5.3

    Reverse an array using two pointers, one starting at each end, without using any index inside the loop.

    Sample input
    6
1 2 3 4 5 6
    Expected output
    6 5 4 3 2 1
    Hint

    int *p = a; int *q = a + n - 1; swap *p and *q, then p++ and q-- while p < q.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, a[100];
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", a + i);   /* a + i is &a[i] */
    int *p = a, *q = a + n - 1;
    while (p < q) {
        int t = *p; *p = *q; *q = t;
        p++;
        q--;
    }
    for (int *r = a; r < a + n; r++) printf("%d ", *r);
    printf("\n");
    return 0;
}

    Pointers into the same array can be compared with <. Each p++ moves one int forward, 4 bytes, automatically.

    5F. Sort names using an array of pointers

    Practises lesson 5.4, 3.6

    Store five names in an array of pointers and print them in alphabetical order by swapping pointers, not text.

    Sample input
    (none)
    Expected output
    Asha Divya Kiran Meena Ravi
    Hint

    const char *names[] = {...}; compare with strcmp(names[j], names[j + 1]) and swap the two pointers.

    Show solution
    #include <stdio.h>
#include <string.h>
int main(void)
{
    const char *names[] = {"Ravi", "Asha", "Meena", "Kiran", "Divya"};
    int n = 5;
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (strcmp(names[j], names[j + 1]) > 0) {
                const char *t = names[j];
                names[j] = names[j + 1];
                names[j + 1] = t;
            }
    for (int i = 0; i < n; i++) printf("%s ", names[i]);
    printf("\n");
    return 0;
}

    Only addresses move; the strings stay where they are. With a 2-D char array you would need three strcpy calls per swap.

    5G. Copy a file character by character

    Practises lesson 5.5

    Copy input.txt into copy.txt using fgetc and fputc, then print how many characters were copied.

    File input.txt
    Hello file
Second line
    Sample input
    (none)
    Expected output
    Copied 23 characters
    Hint

    Open one file with "r" and the other with "w". Loop until fgetc returns EOF. Store its result in an int.

    Show solution
    #include <stdio.h>
int main(void)
{
    FILE *src = fopen("input.txt", "r");
    if (src == NULL) { printf("Cannot open input.txt\n"); return 1; }
    FILE *dst = fopen("copy.txt", "w");
    if (dst == NULL) { printf("Cannot create copy.txt\n"); fclose(src); return 1; }
    int ch, count = 0;                  /* int, so EOF fits */
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dst);
        count++;
    }
    fclose(src);
    fclose(dst);
    printf("Copied %d characters\n", count);
    return 0;
}

    The assignment inside the while condition reads a character and tests it in one step. Newlines are characters too, so they are counted.

    5H. Count characters, words and lines in a file

    Practises lesson 5.5, 3.5

    Read notes.txt and print the number of characters, words and lines it contains.

    File notes.txt
    C is fast
Files keep data
    Sample input
    (none)
    Expected output
    Characters 26, Words 6, Lines 2
    Hint

    Same in-word flag as the string lab, but reading with fgetc. Count a line at every \n.

    Show solution
    #include <stdio.h>
int main(void)
{
    FILE *fp = fopen("notes.txt", "r");
    if (fp == NULL) { printf("Cannot open notes.txt\n"); return 1; }
    int ch, chars = 0, words = 0, lines = 0, inWord = 0;
    while ((ch = fgetc(fp)) != EOF) {
        chars++;
        if (ch == '\n') lines++;
        if (ch == ' ' || ch == '\n' || ch == '\t') inWord = 0;
        else if (!inWord) { words++; inWord = 1; }
    }
    fclose(fp);
    printf("Characters %d, Words %d, Lines %d\n", chars, words, lines);
    return 0;
}

    This is the logic of the Unix wc command. Spaces, tabs and newlines all end a word.

    5I. Save records, then read back those above average

    Practises lesson 5.1, 5.5

    Read n (roll, marks) pairs and write them to marks.txt with fprintf. Close it, reopen it for reading, compute the average with fscanf, and print the students above average.

    Sample input
    3
101 88
102 64
103 79
    Expected output
    Average = 77.0
101 88
103 79
    Hint

    Read the file twice: once to compute the average, then rewind(fp) and read again to print.

    Show solution
    #include <stdio.h>
int main(void)
{
    int n, roll, m, count = 0;
    float sum = 0;
    FILE *fp = fopen("marks.txt", "w");
    if (fp == NULL) { printf("Cannot create marks.txt\n"); return 1; }
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d %d", &roll, &m);
        fprintf(fp, "%d %d\n", roll, m);
    }
    fclose(fp);

    fp = fopen("marks.txt", "r");
    if (fp == NULL) { printf("Cannot open marks.txt\n"); return 1; }
    while (fscanf(fp, "%d %d", &roll, &m) == 2) { sum += m; count++; }
    float avg = sum / count;
    printf("Average = %.1f\n", avg);
    rewind(fp);                                  /* back to the start */
    while (fscanf(fp, "%d %d", &roll, &m) == 2)
        if (m > avg) printf("%d %d\n", roll, m);
    fclose(fp);
    return 0;
}

    The data survives in marks.txt after the program ends. rewind moves the file position back to the beginning so the file can be read a second time.

    Unit 5 cheat sheet

    The night before: the syntax you must not mix up

    Structures

    A structure groups related values of different types into one record.

    struct student {
    int roll;
    float marks;
};              // ; is required
struct student s = {101, 88.5};
s.marks = 90;   // dot: member

    Watch out: you can copy a whole record with s2 = s1, but you cannot compare with s1 == s2. Compare member by member.

    Arrays of structures

    One record per student, all in one array.

    struct student cls[60];
cls[0].roll = 101;  // 1st
cls[i].marks        // student i

    Watch out: the index goes on the array, not the member: cls[i].marks, never cls.marks[i].

    Nested structures and pointers to them

    A record inside a record, and a pointer that holds a record's address.

    e.dob.year      // chain the dots
struct student *p = &s;
p->marks = 95;  // (*p).marks

    Rule: dot after a variable, arrow after a pointer.

    Pointer arithmetic

    Adding 1 to a pointer moves to the next element, not the next byte.

    int a[4] = {10, 20, 30, 40};
int *p = a;   // = &a[0]
*(p + 2)      // 30, like a[2]
p++;          // now at a[1]

    Remember: p + 1 moves 4 bytes for an int and 8 for a double. a++ is an error, because an array name cannot move.

    2-D arrays and arrays of pointers

    Row first, then column. An array of pointers lists strings of different lengths.

    // a[i][j] is *(*(a + i) + j)
const char *names[] =
    {"Asha", "Ravi", "Shalini"};
printf("%s", names[2]);

    Why it helps: each name uses only the space it needs, and sorting swaps pointers instead of copying text.

    Files: open, use, close

    Every file program follows the same three steps.

    FILE *fp = fopen("a.txt", "r");
if (fp == NULL) return 1;
fscanf(fp, "%d", &m);
fclose(fp);   // saves, releases

    Always check for NULL before using fp. Pairs to know: fprintf/fscanf for formatted data, fputc/fgetc for one character, fputs/fgets for one line.

    Writing secure C

    Never let input decide how much is written into an array.

    fgets(s, sizeof s, stdin);  // not gets
scanf("%19s", name);        // width = size - 1
printf("%s", text);         // not printf(text)
if (fp == NULL) return 1;   // check fopen

    Remember: check every index, every size and every return value. Validate input before using it.
