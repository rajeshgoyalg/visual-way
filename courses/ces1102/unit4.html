Unit 4 lessons

    Unit 4: Functions and pointers

    Big programs are built from small, named pieces. This unit shows how to split work into functions, how values travel between them, what a memory address is, and how a function can call itself.

    4.1

    Functions: declare, define, call

    Lecture L22

    A function is a vending machine. Put inputs in (coins and a choice), it does its work inside, and one result comes out.

    Functions let you write a piece of logic once and use it many times, test it on its own, and read main like a summary. You already use library functions such as printf and sqrt; now you write your own.

    A function has three parts. The prototype (declaration) tells the compiler its name, return type and parameter types: int add(int, int);. The definition is the actual body. The call runs it: add(3, 4).

    The values in the call are the actual arguments. The names in the definition's brackets are the formal parameters. At the call, each actual value is copied into its formal parameter, in order. The tracer shows a call happening, with a fresh box of memory (a stack frame) for the function.

    Traps that cost marks

    • Calling a function before it is declared gives a warning or error. Put the prototype above main.
    • The number, order and types of actual arguments must match the formal parameters.
    • The prototype ends with a semicolon; the definition header does not.

    4.2

    Return values and scope

    Lecture L23 with tutorial T8

    What happens in a function stays in the function, unless it is returned.

    A function either returns one value with return (its type is the return type) or returns nothing, in which case its type is void. Combining "takes arguments or not" with "returns or not" gives the four categories exam questions love:

    CategoryExample prototypeTypical use
    No arguments, no returnvoid line(void);Print a fixed banner
    Arguments, no returnvoid printTable(int n);Display results inside the function
    No arguments, returnsint readMarks(void);Read and validate input, hand back the value
    Arguments and returnsfloat area(float r);Pure calculation; the most reusable

    Scope is where a name can be used. A local variable is declared inside a function or block and exists only while that block runs; another function can have its own variable with the same name without any clash. A global variable is declared outside all functions and is visible to every function below it. If a local and a global share a name, the local one hides the global inside that block.

    Prefer locals and pass values through parameters. Globals make it hard to tell which function changed what.

    #include <stdio.h>
int isPrime(int n);              // prototype: argument and return
int main(void)
{
    for (int k = 2; k <= 20; k++)
        if (isPrime(k)) printf("%d ", k);
    return 0;
}
int isPrime(int n)
{
    if (n < 2) return 0;
    for (int d = 2; d * d <= n; d++)
        if (n % d == 0) return 0;    // return ends the function immediately
    return 1;
}

    Traps that cost marks

    • A function can return only one value. To send back two, use pointers (lesson 4.4).
    • Code after return in the same path never runs.
    • A non-void function that reaches its end without return gives the caller garbage.

    Quick check

    4.3

    Pointers

    Lecture L25

    A variable is a house. Its value is the person living there. A pointer is a slip of paper with the house's address written on it.

    Every variable lives at a memory address. The operator & ("address of") gives it: &x. A pointer is a variable that stores an address. Declare it with a star: int *p; means "p holds the address of an int".

    Once p = &x;, the expression *p means "the value at the address in p", which is x itself. This is dereferencing. Reading *p reads x; writing *p = 20; changes x. The star does two jobs: in a declaration it says "this is a pointer"; in an expression it says "go to that address".

    Traps that cost marks

    • int *p; followed by *p = 5; writes to a random address. Initialise pointers: int *p = NULL; or = &x.
    • In int *p, q; only p is a pointer. q is a plain int.
    • Print an address with %p, not %d.

    Quick check

    4.4

    Call by value and call by reference

    Lecture L26

    Giving a friend a photocopy of your notes versus giving them your notebook. Scribbles on the photocopy never reach you.

    By default C passes arguments by value: the function gets copies, so changing a parameter cannot change the caller's variable. That is why a simple swap function fails.

    To let a function change the caller's variables, pass their addresses and let the function use pointers. This is call by reference (strictly, C passes the address by value, which has the same effect). You already used it: scanf("%d", &n) passes the address of n so scanf can write into it. Switch between the two versions below and watch main's a and b.

    Traps that cost marks

    • Calling swap(a, b) when the function expects int *. Pass &a, &b.
    • Inside the function, x = y; swaps the pointers, not the values. You need *x and *y.
    • Use pointer parameters to "return" more than one result, for example the minimum and maximum of an array.

    Quick check

    4.5

    Nesting functions and passing arrays

    Lecture L27 with tutorial T9

    You hand a whole cupboard to someone by giving them the cupboard's location, not by carrying out every shelf.

    Nesting means one function calls another, which may call another. main calls average, which calls total. Each call gets its own frame on the stack; when a function returns, its frame disappears and control goes back to exactly where it was called. (C does not allow defining a function inside another function, only calling one from another.)

    When you pass an array, C passes the address of its first element, not a copy. So the function works on the original array, and changes it makes are visible to the caller. Because the function cannot know the length, pass the size as a separate parameter. For a 2-D array, the column count must be written in the parameter: void show(int m[][3], int rows), because C needs it to compute where each row starts.

    void show(int m[][3], int rows)       // column size is required
{
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++)
            printf("%4d", m[i][j]);
        printf("\n");
    }
}
float average(int a[], int n) { return (float)total(a, n) / n; }  // nesting: calls total

    Traps that cost marks

    • Inside the function, sizeof(a) gives the size of a pointer, not of the array. Always pass n.
    • Pass the array name alone: total(marks, 4), not total(marks[], 4) or total(marks[4], 4).
    • void f(int m[][]) is invalid. The second dimension must be given.

    Quick check

    4.6

    Recursion

    Lectures L28 and L29

    Russian dolls. To reach the smallest doll you open a doll that contains a smaller doll, until one does not open. Then you close them back up in reverse.

    A recursive function calls itself on a smaller version of the same problem. Every recursive function needs two parts. The base case answers the smallest problem directly and stops the chain. The recursive case breaks the problem down and calls itself. For factorial: fact(1) = 1 is the base case, and fact(n) = n × fact(n − 1) is the recursive case.

    Each call waits for the one it made. The calls pile up on the call stack (winding), and when the base case returns, the answers flow back down (unwinding). Pick n below and watch the stack grow and shrink.

    Recursion is a different way of thinking, not a faster one. A loop usually uses less memory. Recursion shines when the problem is naturally self-similar: factorials, Fibonacci, GCD, reversing, and later trees and divide-and-conquer sorts.

    Traps that cost marks

    • No base case, or a base case that is never reached, means calls pile up until the program crashes with a stack overflow.
    • The recursive call must move toward the base case: fact(n - 1), not fact(n).
    • Plain recursive Fibonacci recomputes the same values many times, so fib(40) is very slow.

    Easy

    4A. A power function

    Practises lesson 4.1, 4.2

    Write long power(int x, int n) using a loop, and call it from main to print x to the power n.

    Sample input
    2 10
    Expected output
    2^10 = 1024
    Hint

    Prototype above main, definition below. Start the result at 1.

    Show solution
    #include <stdio.h>
long power(int x, int n);              /* prototype */
int main(void)
{
    int x, n;
    scanf("%d %d", &x, &n);
    printf("%d^%d = %ld\n", x, n, power(x, n));
    return 0;
}
long power(int x, int n)
{
    long r = 1;
    for (int i = 1; i <= n; i++)
        r *= x;
    return r;
}

    The function takes arguments and returns a value, the most reusable category. %ld prints a long.

    Easy

    4B. Largest of three with a function

    Practises lesson 4.1, 4.2

    Write int largest(int a, int b, int c) and use it to print the largest of three numbers.

    Sample input
    7 19 4
    Expected output
    Largest = 19
    Hint

    Find the larger of a and b first, then compare with c.

    Show solution
    #include <stdio.h>
int largest(int a, int b, int c)
{
    int m = (a > b) ? a : b;
    return (m > c) ? m : c;
}
int main(void)
{
    int x, y, z;
    scanf("%d %d %d", &x, &y, &z);
    printf("Largest = %d\n", largest(x, y, z));
    return 0;
}

    Defining the function above main means no separate prototype is needed. The actual arguments x, y, z are copied into a, b, c.

    Medium

    4C. Minimum and maximum through pointers

    Practises lesson 4.4, 4.5

    Write void minMax(int a[], int n, int *mn, int *mx) that sends back both the smallest and largest element.

    Sample input
    6
8 3 15 -2 9 4
    Expected output
    Min = -2, Max = 15
    Hint

    A function can return only one value, so write the answers through the pointer parameters with *mn = ... .

    Show solution
    #include <stdio.h>
void minMax(int a[], int n, int *mn, int *mx)
{
    *mn = *mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < *mn) *mn = a[i];
        if (a[i] > *mx) *mx = a[i];
    }
}
int main(void)
{
    int n, a[100], lo, hi;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    minMax(a, n, &lo, &hi);
    printf("Min = %d, Max = %d\n", lo, hi);
    return 0;
}

    main passes the addresses &lo and &hi, so the function writes straight into main’s variables: call by reference.

    4D. Sort and print with functions

    Practises lesson 4.5

    Write sortArray(int a[], int n) (any sort from Unit 3) and printArray(int a[], int n), and use both from main.

    Sample input
    5
29 10 14 37 13
    Expected output
    10 13 14 29 37
    Hint

    The array is passed by address, so sorting inside the function sorts main’s array.

    Show solution
    #include <stdio.h>
void sortArray(int a[], int n)
{
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
}
void printArray(int a[], int n)
{
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
}
int main(void)
{
    int n, a[100];
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    sortArray(a, n);
    printArray(a, n);
    return 0;
}

    Neither function returns anything (void); sortArray changes the caller’s array directly, and main stays a short summary.

    Medium

    4E. Trace of a matrix: passing a 2-D array

    Practises lesson 4.5

    Write int trace(int m[][10], int n) that returns the sum of the main diagonal of an n × n matrix.

    Sample input
    3
1 2 3
4 5 6
7 8 9
    Expected output
    Trace = 15
    Hint

    The diagonal elements are m[i][i]. The column size must appear in the parameter.

    Show solution
    #include <stdio.h>
int trace(int m[][10], int n)
{
    int s = 0;
    for (int i = 0; i < n; i++)
        s += m[i][i];
    return s;
}
int main(void)
{
    int n, a[10][10];
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            scanf("%d", &a[i][j]);
    printf("Trace = %d\n", trace(a, n));
    return 0;
}

    int m[][10] tells the compiler each row is 10 ints long, so it can find m[i][i]. The declared column size must match the array in main.

    Exam level

    4F. Decimal to binary with recursion

    Practises lesson 4.6

    Write a recursive function that prints the binary form of a non-negative integer.

    Sample input
    13
    Expected output
    1101
    Hint

    Print the binary of n / 2 first, then the last bit n % 2. The base case is n < 2.

    Show solution
    #include <stdio.h>
void toBinary(int n)
{
    if (n < 2) {               /* base case: 0 or 1 */
        printf("%d", n);
        return;
    }
    toBinary(n / 2);           /* higher bits first */
    printf("%d", n % 2);       /* then this bit */
}
int main(void)
{
    int n;
    scanf("%d", &n);
    toBinary(n);
    printf("\n");
    return 0;
}

    The printf after the recursive call runs during unwinding, which is why the bits come out in the right order without storing them.

    Exam level

    4G. Recursive binary search

    Practises lesson 3.2, 4.6

    Write int bsearch_r(int a[], int low, int high, int key) that returns the index of key, or -1.

    Sample input
    7
2 5 8 12 16 23 38
23
    Expected output
    Found at index 5
    Hint

    The base case is low > high (not found). Each call searches one half.

    Show solution
    #include <stdio.h>
int bsearch_r(int a[], int low, int high, int key)
{
    if (low > high) return -1;              /* base case: empty range */
    int mid = (low + high) / 2;
    if (a[mid] == key) return mid;
    if (key < a[mid]) return bsearch_r(a, low, mid - 1, key);
    return bsearch_r(a, mid + 1, high, key);
}
int main(void)
{
    int n, a[100], key;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    scanf("%d", &key);
    int pos = bsearch_r(a, 0, n - 1, key);
    if (pos == -1) printf("Not found\n");
    else printf("Found at index %d\n", pos);
    return 0;
}

    The while loop from lesson 3.2 becomes recursion: low and high travel as parameters instead of being updated in place.

    Exam level

    4H. GCD and LCM

    Practises lesson 4.6

    Write a recursive gcd function using Euclid’s rule, then print both the GCD and the LCM of two numbers.

    Sample input
    12 18
    Expected output
    GCD = 6, LCM = 36
    Hint

    gcd(a, b) = gcd(b, a % b), and gcd(a, 0) = a. LCM = a × b / GCD.

    Show solution
    #include <stdio.h>
int gcd(int a, int b)
{
    if (b == 0) return a;
    return gcd(b, a % b);
}
int main(void)
{
    int a, b;
    scanf("%d %d", &a, &b);
    int g = gcd(a, b);
    printf("GCD = %d, LCM = %d\n", g, a / g * b);
    return 0;
}

    Writing a / g * b instead of a * b / g divides first, which keeps the intermediate value smaller and avoids overflow.

    Unit 4 cheat sheet

    The night before: the syntax you must not mix up

    The three parts of a function

    Declare it, call it, define it.

    // prototype
int add(int, int);

// call
s = add(a, b);

// definition
int add(int x, int y) {
    return x + y;
}

    Remember: The actual arguments (a, b) are copied into the formal parameters (x, y), in order. The prototype ends with a semicolon.

    Return values and scope

    A function returns one value, or nothing (void). A variable is visible only inside its braces.

    void line(void);  // no value
float area(float);  // float

int count = 0;  // global
void f(void) {
    int t = 1;  // local
}

    Watch out: return gives back only one value. A local variable hides a global one with the same name.

    Pointers

    A pointer stores the address of another variable.

    int x = 10;
int *p = &x;  // address of x
*p = 20;      // changes x
printf("%d", *p);  // 20

    Remember: &x means "address of x"; *p means "the value at p". Set unused pointers to NULL.

    Call by value and by reference

    A plain argument is a copy. An address lets the function change the original.

    void f(int n)  { n = 5; }
void g(int *n) { *n = 5; }

f(a);    // a unchanged
g(&a);   // a becomes 5

    Remember: To change the caller’s variable, pass its address and write through *. That is why scanf needs &.

    Passing arrays

    An array is passed as the address of its first element, never copied.

    int total(int a[], int n);
total(marks, 4);   // no []

void show(int m[][3], int r);

    Watch out: Changes inside the function change the original array. Always pass the size, and give the column count for a 2-D array.

    Recursion

    A function that calls itself on a smaller version of the problem.

    int fact(int n) {
    if (n <= 1)  // base case
        return 1;
    return n * fact(n - 1);
}

    Watch out: No base case means the calls never stop and the stack overflows. Each call must move closer to the base case.
