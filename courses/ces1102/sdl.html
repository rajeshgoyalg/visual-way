Self-directed learning projects

The course plan sets 16 projects for 54 hours of self-directed learning, all for CO3 (arrays and strings). Assignment 2 is an SDL-LMS quiz, so these projects feed straight into marks. Work through the milestones in order; each has a hint. The reference solution unlocks when every milestone is ticked.

Student records (1 to 4, 16)

Marks analysis, grading, linear search, linear versus binary search, and an integrated system that combines them.

Products (5 to 8)

Inventory, menu-driven search, catalogue sorting, and a measured comparison of bubble and selection sort.

Text (9 to 12)

Text statistics, a mini dictionary, keyword search and a library manager, all built on strings.

Matrices (13 to 15)

A matrix calculator, utility consumption reports and exam seating with 2-D arrays.
